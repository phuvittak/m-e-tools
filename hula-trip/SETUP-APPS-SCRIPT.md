# 🌺 วิธีติดตั้งระบบ Hula Hula (ฝั่งเซิร์ฟเวอร์ — ปลอดภัย)

ทำบน **คอมพิวเตอร์** ครั้งเดียว (~10 นาที) หลังจากนั้นทุกคนเข้าผ่านมือถือได้เลย

ระบบนี้:
- อ่านข้อมูลสมาชิกจากชีต **"data v.1"** โดยตรง (รหัส → กรองเฉพาะข้อมูลคนนั้น)
- ข้อมูลบัตร/บัญชี **ไม่หลุดไปหน้าเว็บ** (กรองที่เซิร์ฟเวอร์ Google)
- ผลการลงทะเบียนทริปถูกบันทึกไปชีตใหม่ที่ **คุณเป็นเจ้าของ** (สร้างให้อัตโนมัติ)

---

## ข้อกำหนดก่อนเริ่ม
- บัญชี Google ที่คุณใช้ ต้องมี **สิทธิ์ "ดู" ชีต data v.1** (ตอนนี้คุณมีลิงก์ดูได้แล้ว ✓)

## ขั้นตอน

**1) เปิด Apps Script**
- ไปที่ https://script.google.com → **New project (โปรเจกต์ใหม่)**

**2) ใส่โค้ด 2 ไฟล์** (ก๊อปจากในโฟลเดอร์ `hula-trip/`)
- ไฟล์ `Code.gs` → ลบโค้ดเดิม วางเนื้อหา `Code.gs`
- กด **＋ → HTML** ตั้งชื่อ `Index` (ไม่ต้องใส่ .html) → วางเนื้อหา `Index.html`

**3) ตั้ง manifest + สิทธิ์**
- กดไอคอน ⚙️ **Project Settings** → ติ๊ก **"Show appsscript.json manifest file"**
- กลับมาที่ Editor → เปิดไฟล์ `appsscript.json` → วางเนื้อหา `appsscript.json`

**4) ทดสอบสิทธิ์ (ครั้งแรก)**
- เลือกฟังก์ชัน `pingServer` ด้านบน → กด **▶ Run**
- เด้งขออนุญาต → เลือกบัญชี → **Advanced → Go to project (unsafe) → Allow**
- ดู Log (Ctrl+Enter) ต้องเห็นจำนวนสมาชิก = อ่านชีตได้แล้ว ✓

**5) Deploy เป็นเว็บแอป**
- มุมขวาบน **Deploy → New deployment → ⚙️ → Web app**
- **Execute as:** Me (บัญชีคุณ)
- **Who has access:** Anyone  ← เพื่อให้สมาชิกทุกคนเข้าได้
- กด **Deploy** → ก๊อป **URL ที่ลงท้าย `/exec`**

**6) เสร็จ!** ส่ง URL `/exec` ให้สมาชิก → กรอกรหัส (เช่น `PPARmvo`) → ดูข้อมูล + ลงทะเบียนทริปได้เลย

## หมายเหตุ
- **รหัสสมาชิก** เป็นรหัส 7 ตัว เช่น `PPARmvo`, `PPpSMM2`, `WKFQX2O`
- ดูผลการลงทะเบียนทั้งหมด: รันฟังก์ชัน `getRegSheetUrl` แล้วเปิดลิงก์ที่ได้ (ชีตของคุณเอง)
- ถ้าชื่อแท็บ/คอลัมน์ในชีตเปลี่ยน ระบบยังหาอัตโนมัติได้ (ตรวจจับจากรูปแบบรหัส+เลขบัตร)
- อัปเดตโค้ดภายหลัง: แก้ไฟล์ → **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**
