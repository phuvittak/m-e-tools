# 🌺 วิธีติดตั้งระบบ Hula Hula (Excel → เว็บ → Sheet อัตโนมัติ)

ทำบน **คอมพิวเตอร์** ครั้งเดียว (~10 นาที) หลังจากนั้นทุกคนเข้าผ่านมือถือได้เลย

**สายข้อมูล:** ไฟล์ Excel บน OneDrive ──ซิงค์อัตโนมัติ──▶ Google Sheet (ของคุณ) ──▶ เว็บ (ใช้งานหลัก)

- ข้อมูลบัตร/บัญชี **ไม่หลุดไปหน้าเว็บ** (เซิร์ฟเวอร์กรองเฉพาะรหัสที่กรอก)
- ผลการลงทะเบียนถูกบันทึกในแท็บ "การลงทะเบียน" ของชีตเดียวกัน

---

## เตรียม Excel บน OneDrive
- เปิดไฟล์ Excel → **แชร์ (Share)** → ตั้งเป็น **"ทุกคนที่มีลิงก์ดูได้ (Anyone with the link)"**
- ลิงก์ปัจจุบันที่ตั้งไว้ในโค้ด (`EXCEL_SHARE_URL` ใน `Code.gs`):
  `https://1drv.ms/x/c/d4226e2b85a84b3d/IQB6...`  ← ถ้าเปลี่ยนไฟล์ แก้ลิงก์ตรงนี้

## ขั้นตอน
1. เปิด https://script.google.com → **New project**
2. **Code.gs** → ลบของเดิม วางเนื้อหา `Code.gs`
3. กด **＋ → HTML** ตั้งชื่อ `Index` → วางเนื้อหา `Index.html`
4. ⚙️ **Project Settings** → ติ๊ก **Show appsscript.json** → กลับมาวางเนื้อหา `appsscript.json`
5. เพิ่มบริการ: เมนูซ้าย **Services (＋)** → เพิ่ม **Drive API**
6. เลือกฟังก์ชัน **`syncFromExcel`** → กด **▶ Run**
   - เด้งขออนุญาต → Advanced → Go to project → **Allow** (Sheets/Drive/ดึงเน็ต)
   - จะ **ดึง Excel จาก OneDrive → เขียนลง Google Sheet ทันที**
   - ตรวจผล: ดู Log ต้องขึ้นว่าซิงค์กี่แถว (หรือรัน `pingServer` ดูจำนวนสมาชิก > 0)
7. **ตั้งซิงค์อัตโนมัติ** (ไม่ต้องเขียนโค้ด): เมนูซ้าย **⏰ Triggers → Add Trigger**
   - Function: **`syncFromExcel`** · Event source: **Time-driven** · **Hour timer → Every 6 hours** → **Save**
8. **Deploy → New deployment → Web app**
   - Execute as: **Me** · Who has access: **Anyone** → **Deploy** → ก๊อป URL `…/exec`
9. ส่ง URL ให้สมาชิก → กรอกรหัส (เช่น `PPARmvo`) → ใช้งานได้เลย

## ฟังก์ชันที่ควรรู้ (รันในหน้า Apps Script)
| ฟังก์ชัน | หน้าที่ |
|---|---|
| `syncFromExcel` | ซิงค์ Excel → Sheet เดี๋ยวนั้น (รันตอนติดตั้ง + ตั้ง trigger ให้รันเองทุก 6 ชม.) |
| `pingServer` | ตรวจว่าอ่านข้อมูลได้ + จำนวนสมาชิก + เวลาซิงค์ล่าสุด |
| `getWorkSheetUrl` | ลิงก์เปิด Google Sheet ปลายทาง (ดูข้อมูล + การลงทะเบียน) |

## หมายเหตุ
- ระบบหาแท็บข้อมูลสมาชิกอัตโนมัติ (จับจากรูปแบบ รหัส + เลขบัตรประชาชน) — ชื่อแท็บเปลี่ยนได้
- โครงสร้างที่รองรับ: คอลัมน์เรียง `รหัส | คำนำหน้า | ชื่อ | เลขบัตร | บัญชี | ธนาคาร | สาขา | เบอร์ | วันที่ | เวลา | ยอดเงิน`
- แก้ Excel บน OneDrive → ภายใน 6 ชม. เว็บได้ข้อมูลใหม่เอง (หรือรัน `syncFromExcel` ให้ทันที)
