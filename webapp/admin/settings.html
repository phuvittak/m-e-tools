โปรโมชั่นหน้าแรก (แบนเนอร์ใต้ส่วนหัว)

พิมพ์ {dd} ตรงไหน ระบบจะแทนด้วยเลขโปรซ้ำจาก “วันที่โปรซ้ำ” ด้านล่างให้เอง (เช่น 6.6 / 8.8 / 11.11) — ตั้งครั้งเดียว หัวข้อเปลี่ยนตามวันที่เองไม่ต้องแก้ · {date} = วันที่ไทย เช่น “6 มิ.ย.”

🗓️ โปรวันที่ซ้ำ (เช่น 6.6, 8.8) — แนะนำ

ติ๊ก “ทำซ้ำทุกเดือน” แล้วโปรจะ โผล่เองทุกวันที่ซ้ำเดือน · เริ่ม 2 ทุ่มของวันเริ่ม (ก่อนวันโปร) แล้วจบตามจำนวนวันหลัง · {dd} เปลี่ยนตามเดือนให้เอง เช่น มิ.ย.→6.6, ส.ค.→8.8

ถ้าตั้ง “วันที่โปรซ้ำ” ด้านบนแล้ว ช่องนี้ไม่ต้องกรอก · เว้นว่างทั้งหมด = แสดงตลอด

เห็นรูปทั้งหมดที่มี · กด × บนรูปเพื่อลบทีละใบ · ลูกค้าจะปัดดูทีละใบ · บน LINE ส่งเป็นการ์ดเลื่อนได้สูงสุด 10 รูป

ระบบจะ broadcast หาเพื่อนทั้งหมดของ LINE OA ครั้งเดียวในวันเริ่มโปร (วันที่โปรซ้ำลบจำนวนวันที่ตั้งไว้ เช่น 6.6 เริ่มก่อน 3 วัน = ส่ง 3 มิ.ย.) · ต้องตั้ง “วันที่โปรซ้ำ” หรือ “วันเริ่มแสดง” ด้านบน · (ช่องทางอื่น เช่น Messenger/IG ยังไม่ได้เชื่อมบอท จึงยังส่งไม่ได้)

ภาษีมูลค่าเพิ่ม (VAT) & รับบัตร

⚠️ VAT คือภาษีที่ร้านเก็บแล้วนำส่งกรมสรรพากรเอง (ยื่น ภ.พ.30) ไม่มีใครหักให้อัตโนมัติ · ถ้าราคาสินค้าที่ตั้งไว้รวม VAT อยู่แล้ว ให้เลือก “ราคารวม VAT แล้ว” เพื่อไม่คิดซ้ำ

ต้องเชื่อมเกตเวย์ (Omise/GB Prime Pay) + ใส่ API key ก่อนปุ่มบัตรถึงใช้ได้จริง — ตอนนี้ตั้งค่าเตรียมไว้ก่อนได้
