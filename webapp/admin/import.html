นำเข้าสินค้า

นำเข้าจากไฟล์ Excel / CSV ของร้าน (แนะนำ) — เลือกชีต จับคู่คอลัมน์ ตรวจสอบ แล้วเพิ่มเข้าคลังทีเดียวหลายรายการ

📥 นำเข้าจากไฟล์ Excel / CSV ของร้าน แนะนำ

รองรับ .xlsx / .xls / .csv — เลือกไฟล์รายการสินค้าของร้าน → เลือกชีตและแถวหัวตาราง → จับคู่คอลัมน์ให้ตรงกับช่องสินค้า → กดดูตัวอย่าง → เพิ่มเข้าคลัง (ระบบจะข้ามแถวที่ไม่มีชื่อสินค้าอัตโนมัติ)
⚡ วิเคราะห์ทั้งไฟล์อัตโนมัติ (แนะนำ)
กดปุ่มเดียว ระบบจะอ่าน ทุกชีต ในไฟล์ เดาหัวตาราง+คอลัมน์ให้เอง วิเคราะห์แบรนด์จากชื่อสินค้า แล้วสรุปทั้งไฟล์ให้ดูก่อนเพิ่ม
หรือจับคู่คอลัมน์เอง (กรณีไฟล์ซับซ้อน อยากเลือกชีต/คอลัมน์เอง):
จับคู่คอลัมน์ — เลือกว่าคอลัมน์ไหนในไฟล์ตรงกับข้อมูลสินค้าแต่ละช่อง (ระบบเดาให้แล้ว แก้ได้)

🧹 ล้างรายการซ้ำในคลัง

ตรวจสินค้าทั้งคลัง ถ้าซ้ำกัน (รหัส SKU ซ้ำ หรือชื่อซ้ำ) จะเก็บไว้ตัวเดียว (ตัวที่ข้อมูลครบสุด) แล้วลบที่เหลือ — มีให้ยืนยันก่อนลบ

ตัวอย่างข้อมูล

ตรวจสอบความถูกต้องก่อนเพิ่ม — แสดงสูงสุด 25 แถวแรก
หลังเพิ่มแล้ว ไปที่หน้า คลังสินค้า เพื่อตรวจ/แก้รูป-หมวดหมู่ และกดปุ่ม “ซิงค์ขึ้นบอท LINE” เพื่อส่งให้บอทเห็นสินค้าใหม่

📎 นำเข้าจาก URL (AI) ทางเลือก

วาง URL หน้าสินค้าจากเว็บใดก็ได้ — ระบบจะ fetch HTML แล้วให้ AI แยกข้อมูลสินค้าให้
เว็บอ้างอิงแนะนำ (คลิกเพื่อเปิด):
🔧 shop.ktw.co.th 🛠️ itoolmart.com ⚡ dewalt.co.th

📋 หรือวางข้อความดิบ

Copy ข้อมูลสินค้า (ชื่อ สเปค ราคา ฯลฯ) แล้ววางในช่องนี้แทน URL
