🎨 Rich Menu Generator

สร้างรูป Rich Menu ขนาด 2500×1686 px (สเปก LINE) แล้วโหลดไปอัปใน LINE OA Manager
วิธีใช้:
1. กด ดาวน์โหลด PNG → ได้ไฟล์ richmenu-metools.png
2. เปิด LINE OA Manager → ริชเมนู → + สร้างใหม่
3. เลย์เอาต์: เลือก "ใหญ่ - 6 ช่อง 2×3"
4. กด เลือกรูป → อัปโหลดไฟล์ที่เพิ่งดาวน์โหลด
5. ตั้ง action ของแต่ละช่อง:
  • ช่อง 1 (ซ้ายบน "ดูเครื่องมือ") → ส่งข้อความ: ดูสินค้า
  • ช่อง 2 (กลางบน "โปรโมชั่น") → ส่งข้อความ: โปร
  • ช่อง 3 (ขวาบน "เช่ารายวัน") → ส่งข้อความ: เช่า
  • ช่อง 4 (ซ้ายล่าง "ที่อยู่") → ส่งข้อความ: ที่อยู่
  • ช่อง 5 (กลางล่าง "โทรหาเรา") → URL: tel:0813706466
  • ช่อง 6 (ขวาล่าง "ติดต่อเจ้าของ") → ส่งข้อความ: ติดต่อเจ้าของ
6. ชื่อเมนู: เมนูหลัก | ช่วงเวลาแสดง: ไม่จำกัด | ติ๊ก "แสดงเป็นเริ่มต้น"
7. กด บันทึก → เปิดใช้งาน
