# M.E. Tools

A small collection of personal command-line tools for Windows.

## Tools

| Tool | Description |
|------|-------------|
| `tools/Get-WordCount.ps1` | Counts the words in a text file. |

## Usage

```powershell
.\tools\Get-WordCount.ps1 -Path notes.txt
```

This repository is a work in progres — more tools will be added over time.
