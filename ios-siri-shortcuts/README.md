# คู่มือ Siri Shortcuts ภาษาไทย — สั่งงาน iPhone ด้วยเสียง 🗣️📱

สั่งงาน iPhone ด้วยเสียงไทย/อังกฤษโดย **ไม่ต้องเขียนโค้ด ไม่ต้องมี Mac** ใช้แค่
แอป **ทางลัด (Shortcuts)** ที่ติดมากับเครื่อง + **Siri**

> ✅ ข้อดีของวิธีนี้: พูด **"หวัดดี Siri / Hey Siri"** ได้แม้ **จอล็อก/จอดับ**
> (iPhone ฟังด้วยชิปแยก ประหยัดแบต) — เป็นสิ่งที่แอปทั่วไปทำไม่ได้
>
> 🔒 ข้อจำกัด: ปลดล็อกหน้าจอแทนคุณไม่ได้, สร้างคำปลุกชื่ออื่นนอกจาก "Siri" ไม่ได้,
> และสั่งกดปุ่มในแอปอื่นแทนไม่ได้

---

## ส่วนที่ 0 — เปิดใช้ Siri ให้พร้อม (ทำครั้งเดียว)

1. **ตั้งค่า ▸ Siri และค้นหา** (Settings ▸ Siri & Search)
2. เปิด **"ฟังหา 'หวัดดี Siri'"** (Listen for "Hey Siri") → ทำตามขั้นตอนพูดให้เครื่องจำเสียง
3. เปิด **"กดปุ่มด้านข้างเพื่อเรียก Siri"** ไว้ด้วย (เผื่อที่เสียงดัง)
4. **ภาษา (Language):** เลือก **ไทย** ถ้าจะพูดไทยเป็นหลัก
   - 💡 อยากสลับไทย/อังกฤษ? ตั้ง Siri เป็นภาษาเดียวก่อน แล้วเปลี่ยนทีหลังได้ตลอด
     (Siri พูดได้ทีละภาษา แต่ "ชื่อ Shortcut" จะเรียกด้วยภาษาไหนก็ได้ที่คุณตั้ง)
5. เปิด **"อนุญาตให้ Siri ขณะล็อก"** (Allow Siri When Locked) ถ้าต้องการสั่งตอนล็อกจอ

---

## ส่วนที่ 1 — สูตรพร้อมใช้ (ทำตามทีละข้อ)

ทุกสูตรเริ่มเหมือนกัน: เปิดแอป **ทางลัด** ▸ แท็บ **ทางลัดของฉัน** ▸ แตะ **➕** มุมขวาบน

### 🔹 สูตร A — "เปิดยูทูป" (ง่ายสุด)
1. แตะ **เพิ่มการกระทำ** (Add Action)
2. ค้นหา **"เปิดแอป"** (Open App) → เลือก → แตะคำว่า *แอป* แล้วเลือก **YouTube**
3. แตะชื่อทางลัดด้านบน → ตั้งชื่อว่า **เปิดยูทูป** (ชื่อนี้แหละคือสิ่งที่จะพูดกับ Siri)
4. เสร็จ! พูด **"หวัดดี Siri เปิดยูทูป"**

### 🔹 สูตร B — "ค้นยูทูป" (พูดสิ่งที่อยากดูได้)
1. **เพิ่มการกระทำ** → ค้น **"บอกข้อความ"** (Dictate Text) → ตั้งภาษาเป็น *ไทย* (หรือ อังกฤษ)
2. **เพิ่มการกระทำ** → ค้น **"ข้อความ"** (Text) → พิมพ์:
   ```
   https://www.youtube.com/results?search_query=
   ```
   แล้วแตะท้ายบรรทัด เลือกตัวแปร **ข้อความที่บอก** (Dictated Text) ต่อท้าย
3. **เพิ่มการกระทำ** → ค้น **"เปิด URL"** (Open URLs) → มันจะหยิบข้อความจากขั้นก่อนเอง
4. ตั้งชื่อทางลัดว่า **ค้นยูทูป**
5. พูด **"หวัดดี Siri ค้นยูทูป"** → Siri ถามว่าหาอะไร → พูด "เพลงลูกทุ่ง" → เปิดผลค้นหาให้
   > ถ้าคำมีเว้นวรรคแล้วเปิดไม่ติด ให้แทรกการกระทำ **"เข้ารหัส URL"** (URL Encode)
   > คั่นระหว่างขั้นที่ 1 กับ 2

### 🔹 สูตร C — "ค้นกูเกิล"
เหมือนสูตร B แต่ในขั้น "ข้อความ" ใช้:
```
https://www.google.com/search?q=
```
แล้วต่อด้วยตัวแปร **ข้อความที่บอก** → ตั้งชื่อ **ค้นกูเกิล**
> หมายเหตุ: จริงๆ Siri ค้นเว็บให้ได้อยู่แล้วถ้าพูด "หา … ในกูเกิล" — สูตรนี้ไว้คุมปลายทางเอง

### 🔹 สูตร D — "พากลับบ้าน" (นำทาง)
1. **เพิ่มการกระทำ** → ค้น **"แสดงเส้นทางไปยัง"** / ใช้ **"เปิด URL"** กับ:
   ```
   http://maps.apple.com/?daddr=บ้าน&dirflg=d
   ```
   (หรือใช้แอป Google Maps: `comgooglemaps://?daddr=...`)
2. ตั้งชื่อ **พากลับบ้าน** → พูด "หวัดดี Siri พากลับบ้าน"

### 🔹 สูตร E — เปิดแอปอื่นๆ ด้วยเสียง
ใช้ "เปิดแอป" เลือกแอปที่ต้องการ (Facebook, LINE, Gmail, กล้อง ฯลฯ) แล้วตั้งชื่อ
ที่พูดง่าย เช่น "เปิดไลน์", "เปิดกล้อง"

### 🔹 สูตร F — โทรหาคนที่กำหนด
1. **เพิ่มการกระทำ** → ค้น **"โทรหา"** (Call) → เลือกรายชื่อ
2. ตั้งชื่อ **โทรหาแม่** → พูด "หวัดดี Siri โทรหาแม่"
   > อันนี้ Siri ทำได้เองอยู่แล้ว แต่ทำเป็น Shortcut ได้ถ้าอยากรวมหลายขั้น

## ส่วนที่ 2 — ทำงานอัตโนมัติ (Automation) ไม่ต้องพูดด้วยซ้ำ

แอปทางลัด ▸ แท็บ **อัตโนมัติ** (Automation) ▸ **➕** ▸ **สร้างการทำงานอัตโนมัติส่วนตัว**

ตัวอย่างทริกเกอร์ที่ตั้งได้:
| เมื่อ… | ตัวอย่างใช้งาน |
|--------|----------------|
| ⏰ ถึงเวลาที่กำหนด | 7 โมงเช้า เปิดเพลง/อ่านพยากรณ์อากาศ |
| 📍 มาถึง/ออกจากสถานที่ | ถึงบ้าน → เปิด Wi-Fi + เล่นเพลย์ลิสต์ |
| 🔌 เสียบ/ถอดที่ชาร์จ | เสียบชาร์จกลางคืน → เปิดโหมดห้ามรบกวน |
| 📱 เปิดแอปบางตัว | เปิด YouTube → ตั้งความสว่างจอสูงสุด |
| 🏷️ แตะแท็ก NFC | แตะสติกเกอร์ที่โต๊ะทำงาน → เข้าโหมดโฟกัส |

> บางทริกเกอร์ (เวลา, NFC, มาถึงสถานที่) ตั้งให้ **"รันทันทีไม่ต้องถาม"** ได้ใน iOS รุ่นใหม่

---

## ส่วนที่ 3 — ลัดให้เร็วขึ้นอีก

- **เพิ่มลงหน้าโฮม:** ในทางลัด แตะ ⋯ ▸ ปุ่มแชร์ ▸ "เพิ่มไปยังหน้าจอโฮม" → กดเปิดได้เหมือนแอป
- **วิดเจ็ตหน้าล็อก (iOS 16+):** ใส่วิดเจ็ต "ทางลัด" บนหน้าจอล็อก กดปุ่มเดียวทำงาน
- **แตะหลังเครื่อง (Back Tap):** ตั้งค่า ▸ การช่วยการเข้าถึง ▸ การแตะ ▸ แตะด้านหลัง →
  เคาะหลังเครื่อง 2/3 ครั้งให้รัน Shortcut ที่เลือก (ไม่ต้องพูดเลย)
- **พิมพ์สั่ง Siri:** ตั้งค่า ▸ การช่วยการเข้าถึง ▸ Siri ▸ "พิมพ์ถึง Siri" (เผื่อที่เงียบ)

## สรุปข้อจำกัด iOS (อ่านก่อนคาดหวัง)

| อยากได้ | ทำได้ไหมบน iOS |
|--------|----------------|
| พูดตอนล็อกจอแล้วทำงาน | ✅ ผ่าน "Hey Siri" + Shortcuts |
| เปิดแอป/เว็บ/โทร/นำทางด้วยเสียงไทย | ✅ |
| ทำงานอัตโนมัติตามเวลา/สถานที่/NFC | ✅ |
| ตั้งคำปลุกชื่ออื่น (เช่น "จาร์วิส") | ❌ มีแต่ "Siri" |
| ปลดล็อกหน้าจอเอง | ❌ ห้ามเด็ดขาด |
| สั่งกดปุ่ม/เลื่อนจอในแอปอื่นแทนเรา | ❌ (Android ทำได้ผ่าน Accessibility, iOS ไม่ให้) |
| ฟังไมค์เบื้องหลังด้วยแอปเราเอง | ❌ (มีแต่ Siri ระบบ) |
